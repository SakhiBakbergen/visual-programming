# Лабораторная работа №12. Каталог книг (вариант 1)

JavaFX + FXML + JDBC + SQLite. Поля: название, автор, год.

Запуск (JDK 17+, Maven):

    mvn clean javafx:run

В IntelliJ IDEA: File → Open → pom.xml → Open as Project, затем запустить BookApplication.
Файл books.db создаётся в рабочей папке проекта при первом запуске.
